# 実行範囲・外部データ・費用 v4

Claudeの利用希望は維持する。本人用App Serverは127.0.0.1だけで起動し、公式CLIの認証に任せる。第三者の生成要求を開発者のPro契約へ中継する実装、tokenの抽出、共有、制限の迂回は作らない。本人用途と配布製品の条件はA01で公式資料と照合し、未確認は未確認と報告する。ローカルに置くことだけで許可されたと断定しない。

共通SNSはClaudeを呼ばず稼働する。共有データと本人推論を分離し、capabilitiesで提供範囲を明示する。解決できない条件を隠すためにOllama/有料APIへ勝手に変更しない。

Google等の無料枠はSKUごと。旅程1件がAPI1回とは限らず、地点検索・写真・経路区間・候補数で増える。呼出し回数の上限、低い同時実行、bounded retry、許可範囲内キャッシュを設計する。予算通知は停止装置とみなさない。現在の契約・料金表・プロジェクト設定を実行時に確認する。

外部データには出典、取得時刻、保持期限、帰属、maySendToModel、mayExportを付ける。Googleの取得値を無条件でLLM/PDF/SNSへ渡さない。不明ならその用途では使わずblocked/unknownを示す。DBへ保存するユーザー自身の旅行予定とproviderの表示データを区別する。

SNS公開のGPS・自宅住所・秘密メモは初期除外。写真EXIFの位置情報を除く。任意URL画像取得・任意shell・公開DB・無認証管理ポートは禁止。共通DBはserverだけが開く。バックアップとlogsはGitに入れない。
