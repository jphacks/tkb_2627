## 6. fixtureとliveの区別

| 項目 | 状態 |
|---|---|
| 旅程の保存、認証、SNS、グループ、PDF、ICS | 共有サーバーの実機能。ただし試験とreviewのデータはfixture |
| Claudeによる生成 | live確認はM4のPCのみ。他のPC・共有URLからは使えない |
| 経路（Routes） | 限られた条件でliveを確認。国内の公共交通は取得不可（時刻未定として返す）。デモの場所はfixture |
| トイレ・避難所 | fixtureのみ（「架空」表示）。実データのproviderなし |
| 観光ガイドの解説と写真 | Wikipedia（live）。権利のない写真は出さない |
| 運賃・ホーム・営業時間・災害情報 | 取得できなければ「不明」。生成で補わない |
