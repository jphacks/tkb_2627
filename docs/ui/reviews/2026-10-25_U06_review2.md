# U06 レビュー 第2回（#34、M4）

- 隣接する特別な行をなくし、すべての停留所を番号付きのスポット行にする。連続するスポットは矢印（手段と所要時間）だけでつなぐ。
  - 降車停留所（`TravelLeg.transit.alightingStop`）が分かる区間だけ、その区間の直後に番号付きの行として表示する（`lib/places.ts` の `numberEntries`。表と地図は同じ番号付けを使う。停留所は位置を持たないため地図にマーカーはなく、番号が飛ぶ）。
  - 分からない場合は行を作らず、矢印に「公共交通・所要時間（未取得）」だけを出す。
  - 停留所は旅程の項目ではなく区間から導出する表示なので、単独のK10 `move`では保存できない。停留所のハンドルは「その区間の出発側の予定」を動かし、区間と停留所は一緒に動く。
- 金沢のfixture：夕食の後に「香林坊バス停」へ歩き（5分）、停留所からバスでホテルへ。夕食の開始を17:25にして、徒歩10分の到着と一致させた（`packages/fixtures/src/times.test.ts` が各区間の整合を検査する）。
- 入れ替えができない原因：ドラッグ開始と同時に「移動中」の案内が表の上に入り、表が約40px下がるため、隣の予定の下半分に届かなかった。案内を画面下に固定表示（`position: fixed`）にして、表が動かないようにした。
- ハンドル：点線の枠をセル全体に広げ、行の左の青い線と同じ高さにした。
